# 05 · 경제 기억과 AI 위임: 비교 가능한 정보에서 행동으로

[전체 흐름으로](../README.md)

**금융기능:** 정보를 생산·검증하고, 권한 안에서 상품 선택과 실행을 지원한다. 뉴스 수집량보다 어떤 증거가 판단을 바꾸는지가 중요하다.

`관측 → 주체·기간·단위 대사 → 경쟁 가설 → 대응 후보 → 승인된 실행 → 결과·정정 기록`

## 실제 읽은 연구와 실험의 경계

**자체 개발 기록:** `proactive`의 공시 재검토 브랜치는 KB·신한 공개 공시 6건의 26개 수치와 20개 과제를 사용했다. 지원한 비교는 **14/20=70%**다. 주체·상품·측정값·범위·통화·단위·잔액/흐름과 기간을 맞추는 코드가 있다. 수동 metadata와 알려진 사례를 사용한 개발용 pilot이며 독립 holdout이 아니다.

| 저장된 실험: 동일 검증 포함, 각 100회 | 중앙값 |
|---|---:|
| 원문 text 재읽기·추출 | 93.56ms |
| 기존 list 캐시 | 70.52ms |
| dictionary 조회 | 72.96ms |

Dictionary는 재읽기보다 빨랐지만 기존 list 캐시보다 **2.44ms 느렸다**. 분포도 겹친다. 원문 재읽기를 피하는 효과와 일반 캐시 대비 추가 속도 우위를 구별한다. 이 수치는 과거 저장 보고의 결과이며 이번 클라우드 재측정이 아니다. 원문 snapshot이 공개 산출물에 없으므로 독자가 이 저장소만으로 timing을 재현할 수는 없다.

별도 economic-memory 브랜치는 전망 당시 근거·입수시점과 후속 관측을 구분하고, 정정·미관측·비교불가를 따로 남긴다. 과거 cutoff를 넣는 것만으로 전체 과거 경제 그래프가 복원되지는 않는다. 데이터 저장과 문자열 일치가 새 경제적 의미의 발견이나 예측력 검증은 아니다.

## 기관 행동과 경제성 — 자체해석

검토를 재사용하면 반복 작업이 줄 가능성이 있지만 수집·수동 정의·사람 검토·예외 처리까지 포함해야 한다. 고객의 선택을 AI에 위임하면 비교·전환비가 내려가 단순 유통보수는 압박받을 수 있다. 실제 현금 접근·위험 인수·복구 책임을 수행하는 기관의 기능은 남는다. [USDC 약관의 직접 상환 자격](https://www.circle.com/legal/usdc-terms)도 기술적 자동화만으로 없어지는 제약이 아니다.

**조건부가설:** 외부 에이전트가 상품 선택을 널리 맡으면 금융 앱의 고객 접점이 약해질 수 있다. 반대로 은행의 자체 에이전트·신용·계좌 서비스 결합은 관계를 강화할 수 있다. 조회·추천만 자동화되는 경로도 함께 둔다.

**한국 대응 후보:** 읽기·추천·승인·실행·서명·대사·복구를 분리하고, 모델 밖에서 한도·수취인·만료·중복방지를 강제한다. 사람시간·정확도·예측력·실제 수익은 **미확인**이다.

**다음 판별자료:** 처음 보는 공시와 실제 연구자 과제를 고정해 전처리부터 최종 판단까지 비교한다. 예측은 사전에 정의한 시점·대상·기준모형과 비교한다. 금융 실행은 반복 유료 사용, 오류·환불·복구비, 순보수로 별도 검증한다.
