# 03 · 한·미 지급과 한국 은행의 조달·고객 관계

[전체 흐름으로](../README.md)

**금융기능:** 기업이 원화 매출로 달러 대금을 지급하거나, 달러 수출대금을 원화 급여·세금으로 전환한다. FX·신용·정산·반환 책임을 가진 상대방이 필요하다.

## 관측과 기관 행동

**기관주장·기술 실증:** 신한은행은 2026-09-30 기존 기업뱅킹·외화계좌를 유지하고 후방에서 스테이블코인 전송·정산을 처리하는 해외송금 실증을 발표했다. 신청·내부결재·지급·반환을 검증했다고 설명하며 실제 서비스 적용은 후속 검토로 남겼다. 상용 사용량·총비용·순이익으로 확대하지 않는다. [신한 공식 발표](https://shinhangroup.com/kr/archive/press/detail/950)

**기관 설명·파일럿:** 한국은행은 2026-10-08 프로젝트 한강을 은행 예금토큰과 기관용 디지털화폐 기반 사업으로 설명했다. 일반인이 중앙은행 디지털화폐를 직접 보유하는 구조와 구분한다. [한은 설명](https://www.bok.or.kr/portal/bbs/B0000347/view.do?menuNo=201106&nttId=11065408)

**사실·공식 발표:** OCC는 2026-10-21 GENIUS 이행 최종규칙을 발표하고 효력일을 2027-01-18로 명시했다. 발표를 현재 시행이나 개별 발행자의 인가로 읽지 않는다. 세부 준비자산 한도·보상 조문은 이번에 재대조하지 않았다. [OCC 발표](https://www.occ.treas.gov/news-issuances/news-releases/2026/nr-occ-2026-92.html)

## 자금·수익 이동 — 자체해석

`기업 원화예금 → FX 상대방이 달러 공급 → 기존 송금 또는 허용된 토큰 경로 → 수취인의 은행 달러`

원화를 받은 FX 상대방의 자산과 달러 조달을 함께 추적한다. 토큰 전송액 전부를 한국의 새 자본유출로 세지 않는다. 신규 스테이블코인 발행과 기존 보유자 사이의 거래도 다르다. 은행 예금의 총량이 유지돼도 소매예금이 발행사의 집중 예금으로 바뀌면 금리·유동성 위험은 달라질 수 있다.

| 조건부 경로 | 수익·비용의 변화 | 반대 경로와 다음 관측 |
|---|---|---|
| 은행이 기업 화면과 지급 연결을 유지 | FX·현금관리 보수, 신용 고객 유지 가능 | 구축·유동성·준법비가 절감을 넘을 수 있음. 같은 최종 수취액의 전체 견적 비교 |
| 글로벌 플랫폼이 고객 선택을 주도 | 국내 은행은 도매 FX·현금 공급으로 역할 이동 가능 | 은행의 가격 인하·ERP 연계·묶음 서비스로 관계 회복. 실제 고객 이동과 순보수 관측 |
| 원화 수단이 달러 자산 접근을 낮은 비용으로 연결 | 달러 투자·결제 수요 확대 가능 | 원화 급여·세금·대출·헤지 수요가 공존을 지지. 거주자별 실제 자금흐름 확인 |

**한국 대응 후보:** 은행은 원화 신용·계좌 관계에 해외 현금화와 복구를 결합하고, 증권·운용은 적격 상품과 담보 서비스를 붙인다. 지방은행은 공동 인프라의 비용과 고객별 반복 수요를 비교할 수 있다. 은행 전체 이익이 견조하다는 관측만으로 장래 접점 이동 가설을 폐기하지 않는다.

**후속 확인:** 최초 카드 작성에서는 금융위 두 문서 재조회에 실패했다. 이후 11월 1일 최종 보고서 작업에서 하위규정 입법예고문(87838)의 공식 대체 경로를 읽었다. 예고기간과 시행 예정의 확인이며 확정 시행·개별 허용을 뜻하지 않는다. 정책방향 문서(87650), 민간 원화 스테이블코인의 최종 법적 허용, 한국 기관별 실제 계약은 별도 확인 대상이다. [갱신된 근거와 한계](../reports/digital-finance-institutional-response-2026-11-01.md#sources)
