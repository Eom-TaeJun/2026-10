# 이전 공개 안내 검색 실험 — 별도 보존

이전 실험은 공개 고객안내 검색/근거/대상 확인이며 실제 지급지침이나 약관 판단 실험이 아니다. 부모 대화의 독립 검토 요약: 정상 질문 8건에서 단순 검색 A의 근거 적합 7/8, 대상/질문 분류를 추가한 B의 정상 질문 불필요 보류 4/8. 보수적 규칙을 추가해도 정상 사용성이 나빠질 수 있었다.

이번에는 기존 결과를 재채점하거나 새 합성 사례와 합산하지 않았다. 이전 고정 코드 SHA256: `f1cb1cadc242dcbd9a7653ea3e83241eecf132dee0ca81d1eb4dd14dcdbbb99d`.
기존 원결과 위치는 클라우드 `/workspace/kb-public-guide-eval`이며 기존 유동성 PoC는 `/workspace/liquidity-review-20261101`에 별도 보존한다. 경로는 재현용 공개 입력 링크가 아니다. 비공개 원본 코드는 이번 폴더로 복사하지 않았다. 이 파일은 전달된 검토 요약이며 기존 실험의 신규 실행 로그가 아니다.

따라서 새 A에서도 정상건의 불필요 보류를 독립 지표로 유지했다. 이번 작은 합성 표에서 0건이어도 자연어 질문이나 실제 서류에서 문제가 해결됐다는 증거는 아니다.
