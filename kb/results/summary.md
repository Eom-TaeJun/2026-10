# 실행 결과 — 2026-11-01 UTC

Python 표준 라이브러리만 사용했다. 계획/정답을 먼저 고정하고 구현 후 개발 실행, 코드 수정 없이 평가 1회를 수행했다. SHA는 [fixture_freeze.json](fixture_freeze.json), [code_freeze.json](code_freeze.json), 실행시각/환경/코드 SHA와 원출력은 [eval.json](eval.json)에 있다. 이는 동일 작성 주체의 합성 규칙 재현 시험이며 독립 블라인드 평가·통계적 일반화 근거가 아니다.

## A: 합성 청구 행정 검토

평가 16건 = 정상 8 + 예외 8. 예외 정답 이유 총 9개(마지막 1건은 2개 이유).

| 지표 | 기본 접수 SQL | 조건 검토 규칙 |
|---|---:|---:|
| 예외 탐지 TP / 예외 수 | 2/8 | 8/8 |
| 예외 누락 FN / 예외 수 | 6/8 | 0/8 |
| 정상 불필요보류 FP / 정상 수 | 0/8 | 0/8 |
| 이유 집합 완전 일치 / 전체 | 9/16 | 16/16 |
| 인계 이유 누락 / 필요한 이유 | 7/9 | 0/9 |

기본 SQL은 입력 존재와 접수문서만 검사하므로 읽기불가·대상·날짜·규칙·금액 불일치를 놓친다. 양쪽은 같은 전체 입력을 받지만 검사 범위가 다르다. 결과는 명시된 업무 검사의 구현 증거이지 AI 정확도 향상이나 실제 업무시간 절감이 아니다. 모두 `review_required=true`, `payment_authorized=false`이며 정상 상태도 지급승인이 아니다.

예외별 원결과: AE09 필수일자 누락, AE10 읽기불가, AE11 대상 충돌, AE12 존재하지 않는 날짜, AE13 사건일과 선택 규칙 충돌, AE14 금액 차이, AE15 증빙 누락, AE16 필수금액·문서 누락. 실제 KB 약관 버전쌍을 쓰지 않았으므로 실제 적용일 정확도 성과는 N/A.

## B: 합성 시설 의존성과 권리

데이터센터 3곳, 계약 24개 + 중복행 1개. 평가 사건 4개의 정답 영향 계약-사건 쌍 총 24개. 같은 계약이 다른 사건에 포함될 수 있으므로 24개를 서로 독립적인 표본이라고 부르지 않는다.

| 지표 | 자산별 SQL | 의존성 Python | 의존성 SQL |
|---|---:|---:|---:|
| TP / 정답 쌍 | 13/24 | 24/24 | 24/24 |
| FP / 예측 쌍 | 19/32 | 0/24 | 0/24 |
| FN / 정답 쌍 | 11/24 | 0/24 | 0/24 |
| 영향집합 완전일치 / 사건 | 0/4 | 4/4 | 4/4 |
| 알려진 한도 소계 일치 / 사건 | 0/4 | 4/4 | 4/4 |
| 중복·한도누락·권리미확정 필드 완전일치 / 사건 | 0/4 | 4/4 | 4/4 |

자산별 집계와 의존성 조인은 서로 다른 업무 질문에 답한다. 자산 집계가 의존성 정보를 못 받게 한 것이 아니며 입력은 동일하다. 이 차이를 알고리즘 우열이나 블록체인 효과라고 해석하지 않는다. 의존성 SQL과 Python 전체 출력 4/4 일치, 같은 사건 재처리 4/4 일치. SQL로 충분한 범위다.

| 사건 | 영향 계약 수 | 알려진 한도 소계 | 미확정 사항 |
|---|---:|---:|---|
| BE1 gridA, service/capacity | 11 | 8,600 | C12 한도 누락, C05 중복 제거 |
| BE2 coolingX, service | 4 | 4,800 | C22 권리종류 미확정 |
| BE3 cloudP, capacity | 6 | 7,800 | C22 권리종류 미확정, C05 중복 제거 |
| BE4 gridB, 2027-01-01 service | 3 | 6,000 | C22 권리종류 미확정 |

단위는 `synthetic_limit_units`. 미확정 항목 때문에 네 사건 모두 전체 노출 확정값이 아니다. 알려진 한도 소계이며 예상손실·보험료·지급금·수익이 아니다.

## 검증 범위와 미실행

- 경계/결측/중복/지급승인 차단 단위시험 8/8 통과. 시작일 포함·종료일 제외, 0한도와 누락 구별, 같은 시설의 다른 계약 보존, 중복 의존성 행의 조인 증폭 방지를 확인했다.
- 개발 A 8건: 규칙 이유 8/8 일치. 개발 B 2사건: Python/SQL 정답 및 상호출력 2/2 일치. 개발 결과로 수정하지 않았다.
- 실제 서류 OCR, 비정형 언어, 의학·법률·약관 판단, 고객 개인정보, 실계좌·실자금, KB 운영 API 연결은 수행하지 않았다.
- 다중경로 전파, 계약 해지/의존성 이력변경, 공유한도 배분, 충돌하는 중복 ID, 음수/타입 오류 전반, 대규모 처리와 동시성은 미구현이다. 재처리는 순수 함수 결과 일치이며 운영 멱등성/분산처리 시험이 아니다.
- 사람 검수시간과 비용·실무 정확도는 미측정. 시험 실행시간은 계산시간이며 업무시간 절감으로 변환하지 않는다.
- Library 공식 다운로드 실패로 연구 원문 2건은 소비하지 못했다. 업로드/외부게시/원격 push 없음. 이 신규 실험은 Docker나 외부 패키지가 필요 없으며 컨테이너를 만들지 않았다.
